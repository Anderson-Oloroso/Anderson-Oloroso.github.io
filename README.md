# Portafolio Personal
### _Portafolio Web Profesional_ 🚀

#### ✅ Descripción del proyecto:
Este proyecto consiste en un portafolio web personal, refactorizado y optimizado bajo un enfoque **Full Stack / Front-End moderno**. Muestra de forma estética, limpia e interactiva mi trayectoria académica, competencias técnicas, proyectos destacados, perfil profesional e intereses tecnológicos.

## 👾 *Cómo ver el proyecto*
- Visitar la página web publicada en GitHub Pages:
  [anderson-oloroso.github.io](https://anderson-oloroso.github.io)

## 📁 *Estructura del Proyecto*

```text
Anderson-Oloroso.github.io/
├── index.html
├── CSS/
│   └── style.css
├── Js/
│   └── script.js
└── README.md

```

## 💻 *Tecnologías y Herramientas utilizadas*
- **HTML5**: Estructura semántica, accesibilidad y optimización SEO.
- **CSS3**: Diseño responsive con CSS Grid, Flexbox, variables CSS (`:root`), efectos Cyberpunk/Tech y animación fluida.
- **JavaScript (ES6+)**: Navegación dinámica, menú desplegable interactivo en dispositivos móviles y animaciones al scroll mediante *Intersection Observer*.
- **Git & GitHub Pages**: Control de versiones y despliegue continuo en la web.
