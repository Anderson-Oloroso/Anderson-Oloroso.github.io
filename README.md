## 📌 Descripción del Proyecto

Este repositorio contiene el código fuente de mi portafolio web personal, diseñado y refactorizado bajo estándares modernos de desarrollo Front-End (HTML5 semántico, CSS3 moderno con variables y CSS Grid/Flexbox, JavaScript Vanilla ES6+).

## 🛠️ Tecnologías y Herramientas

- **HTML5**: Estructura semántica, accesibilidad (a11y, ARIA) y optimización para motores de búsqueda (SEO).
- **CSS3 Moderno**: Paleta de colores tech (*Dark Slate & Electric Cyan*), maquetación con CSS Grid y Flexbox, variables personalizadas (`:root`), efectos de *Glassmorphism* y diseño 100% responsivo (`clamp()`).
- **JavaScript (ES6+)**: Interactividad ligera, menú de navegación accesible para móviles, *scroll spy* y animaciones con `IntersectionObserver` respetando `prefers-reduced-motion`.
- **Git & GitHub Pages**: Control de versiones distribuido y despliegue continuo.
